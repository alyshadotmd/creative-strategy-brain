# Visual Formats

The library `creative-engine` reads at Step 7. A format is the container for the offer — the production structure an ad takes.

## What goes here

One file per format, named for the format (lowercase, hyphenated). Each records: a plain definition, the medium (video, static, or both), the awareness stages it serves naturally and why, what it's good at (revealing a problem, proving a claim, staging a scene, showing a comparison), production notes, and — once formats have run — which stages it lives or dies at for this brand.

## Rules

- Any format can work at any stage when the messaging is right; the notes say where each lives naturally, not where it's allowed.
- When a format keeps dying at a stage, correct its notes here rather than remembering it.
