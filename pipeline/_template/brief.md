# Brief

Instructions to whoever produces the final asset — the editor for a video, the designer for a static.

Read `overview.md` for the rationale. This file carries the instructions only.

## Fidelity

State which this is before anything else, because it changes how everything below should be read:

- **Word-for-word** — an exact spec. Every choice is made here; deviations need approval.
- **Directional** — the intent and the boundaries are set; the producer's judgement fills the rest.

## Deliverable

What is being made, in what medium, at what dimensions and lengths, and how many variants.

## Instructions

The actual direction, in the order it will be executed.

## Must include

Non-negotiables: claims that must appear, legal or compliance requirements, brand marks, the offer as stated.

## Must not include

From the brand's claims list, plus anything specific to this concept.

## Source material

Paths into `assets/` — see `references.md`.

## Done looks like

What the producer should check before sending it back.
