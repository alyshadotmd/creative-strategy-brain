# Ad Concepts

The log `creative-engine` writes to at the end of every pass. One row per concept. Every row is a full walk of the map; a row with a blank column is not a finished concept.

Coverage gaps show here: which personas have no upper-funnel concepts, which stages have only one trigger moment, which angles have never been tested. Read it before starting a volume run.

| # | Date | Pain / Desire | Persona | Stage | Trigger moment | Angle | Offer | Format | Hook | Status | Result |
|---|---|---|---|---|---|---|---|---|---|---|---|
|   |      |               |         |       |                |       |       |        |      | concept / briefed / live / retired | link to `4. analyze` learnings |

**Column notes**
- *Persona* — the file name in `1. research/customer/personas/`
- *Stage* — the awareness stage the persona is in when the ad finds them
- *Trigger moment* — one line, named by circumstance; the stage transition it drives is implied by *Stage*
- *Angle* — the file name in `2. ideate/messaging-angles/`
- *Offer* — the one-or-two-sentence offer statement from Step 6
- *Format* — the format name from `2. ideate/visual-formats/`
- *Hook* — the opening line, or a reference into `2. ideate/hooks/`
- *Status / Result* — updated as the concept moves through `3. create` and comes back from `4. analyze`
