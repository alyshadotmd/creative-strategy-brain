# Roadmap

What is in flight across the pipeline. One row per concept folder. Read it before opening a new concept — it shows where the work is stacked up and what is waiting on someone else.

| Concept | Persona | Angle | Format | Status | Waiting on | Opened |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

**Column notes**

- *Concept* — the folder name in `pipeline/`
- *Persona* / *Angle* / *Format* — copied from the concept's `overview.md`, so this table can be read without opening anything
- *Status* — the values listed in `README.md`
- *Waiting on* — the person or step blocking it, if any. A concept with no status change and nothing in this column is stalled, not in progress.
